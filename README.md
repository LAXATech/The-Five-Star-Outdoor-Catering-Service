> **Crafting Unforgettable Feasts for Every Occasion in Nagercoil & Beyond.**

## 🌟 Overview

A luxury, production-quality, responsive web application for **The Five Star Outdoor Catering Service** based in Nagercoil, Kanyakumari District, Tamil Nadu.

### Key Pages & Features:
- **Homepage (`/`)**: Cinematic hero, animated countable trust stats, curated services, signature menus carousel, client testimonials, and full-width CTA.
- **Menus & Packages (`/menus`)**: Category and tier filtering (Grand Wedding Feast, Biryani Specials, Pure Veg Traditional, Cocktail & Hi-Tea), package comparison cards (Silver, Gold [Most Popular], Platinum), downloadable seasonal menu deck lead-capture, and embedded budget estimator.
- **Our Services (`/services`)**: Turnkey event capabilities (Outdoor Setup, Live Food Stalls, Professional Staff, Equipment & Logistics, Hygiene & Safety, Custom Menu Planning) and Event Types We Cater To.
- **Gallery & Past Events (`/gallery`)**: Masonry grid with category filter tabs and fullscreen keyboard-accessible lightbox.
- **About Us (`/about`)**: Our story, culinary team chef profiles, FSSAI hygiene standards, and core values.
- **Contact & Quotes (`/contact`)**: 3-column layout featuring direct contact links, Ramanpudur map preview, detailed multi-field quotation form with instant validation, and a "Book a Taste Session" card.
- **Interactive Budget Estimator**: Dynamic calculation based on guest count (100–1,500), menu selection, and service formats.
- **Floating WhatsApp Widget**: Persistent bottom-right quick chat with prefilled message to `+91 94432 09523`.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Tooling**: [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Routing**: [React Router v7](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animation & Effects**: `canvas-confetti`, custom CSS keyframes, and smooth cubic easing counter hooks

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation
```bash
git clone https://github.com/LAXATech/The-Five-Star-Outdoor-Catering-Service.git
cd The-Five-Star-Outdoor-Catering-Service
npm install
```

### Development
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
npm run preview
```
